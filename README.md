# Learning

Practice repository for Java, organized by topic. Each folder is one module
from my Java syllabus, numbered in learning order.

## Folders
| Folder | Content | Status |
|---|---|---|
| java-learning | Core Java, Java 8 to 21 features, coding practice | In progress |

## Rules
- Folders: 01_fundamentals, 02_control_flow, and so on
- Java files: PascalCase, same name as the class (ForLoop.java)
- Run one file: java java-learning\02_control_flow\ForLoop.java
