# Java, Python and SQL Learning Repository

A structured, topic-wise practice repository covering Core Java (Java 8 to 21),
Python fundamentals and SQL, built for software testing, QA automation and
developer interview preparation.

## What is inside
| Folder | Content | Status |
|---|---|---|
| java-learning | Fundamentals, OOP, collections, exception handling, Java 8 to 21 features, multithreading, coding problems | In progress |
| python-learning | Python fundamentals, data structures, scripting | Planned |
| sql-learning | SELECT, joins, GROUP BY, subqueries, data validation queries | Planned |

## Skills practiced
Core Java, object-oriented programming, collections framework, streams and lambdas,
exception handling, Python scripting, SQL queries, problem solving, interview
coding questions.

## How the repository is organized
- Numbered module folders keep topics in learning order (01_fundamentals, 02_control_flow, and so on)
- One file per topic, with a one-line comment at the top describing it
- Java files: PascalCase, same name as the class
- Run one Java file: java java-learning\02_control_flow\ForLoop.java
